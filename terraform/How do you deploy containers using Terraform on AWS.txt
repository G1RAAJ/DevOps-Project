How do you deploy containers using Terraform on AWS?
------------------------------------------------------
Terraform provisions VPC, ALB, ECS cluster, task definition, and Fargate service. 
CI/CD pipeline builds and pushes image to ECR, and ECS service automatically pulls updated image.

1️⃣ ECR Automation (Terraform)
Terraform creates ECR repository.
vi ecr.tf

resource "aws_ecr_repository" "app_repo" {
  name = "my-app-repo"

  image_scanning_configuration {
    scan_on_push = true
  }

  tags = {
    Environment = "shared"
  }
}

2️⃣ Multi-Environment Structure
Real production layout:
terraform-project/
│
├── modules/
│     ├── ecs/
│     ├── vpc/
│
├── environments/
│     ├── dev/
│     ├── staging/
│     └── prod/


Each environment:
Separate backend (S3 key)
Separate ECS service
Separate task definition
Separate ALB target group

3️⃣ GitHub Actions CI/CD
.github/workflows/deploy.yml

vi deploy.yml

name: ECS Deploy Pipeline

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Configure AWS
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: arn:aws:iam::<ACCOUNT_ID>:role/github-oidc-role
          aws-region: ap-south-1

      - name: Login to ECR
        run: |
          aws ecr get-login-password --region ap-south-1 \
          | docker login --username AWS --password-stdin <ACCOUNT_ID>.dkr.ecr.ap-south-1.amazonaws.com

      - name: Build Image
        run: |
          docker build -t my-app .
          docker tag my-app:latest <ACCOUNT_ID>.dkr.ecr.ap-south-1.amazonaws.com/my-app-repo:latest

      - name: Push Image
        run: |
          docker push <ACCOUNT_ID>.dkr.ecr.ap-south-1.amazonaws.com/my-app-repo:latest

      - name: Update ECS Service
        run: |
          aws ecs update-service \
            --cluster demo-ecs-cluster \
            --service nginx-service \
            --force-new-deployment

This pipeline:

Builds image
Pushes to ECR
Triggers ECS redeploy
